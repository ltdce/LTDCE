# Share Allowed for Legion TD Community Enhanced 1.1.5

Download the attached `.w3x` and use the same file for everyone in the lobby. In the pregame mode picker, the host can switch **Share Allowed** from **OFF** to **ON** before confirming. It works with Pick either on or off. During the match, teammates use Warcraft III’s Allies panel to send gold or lumber.

This prerelease is based on the published 1.1.5 map. Automated checks covered the picker and the map archive. Live multiplayer validation is pending. When testing, check both players’ balances after sending each resource, then confirm that opponents cannot receive transfers and that transfers are blocked with the option off.
